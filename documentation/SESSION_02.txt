OBJECTIVE

DEBUGGING PROCESS
----------------------------------------------------------------
Upload Issue Resolved
  - Data capable USB cable sourced
  - ESP32 detected on COM5
  - Code uploading successfully
  - Serial monitor confirmed working at 115200 baud

Software Fixes Attempted
  - ST7735_DRIVER uncommented in User_Setup.h
    (was not defined at all — root cause of first black screen)
  - Tried all tab variants one at a time:
      ST7735_BLACKTAB  ──  no result
      ST7735_GREENTAB  ──  no result
      ST7735_REDTAB    ──  no result
  - RST pin set to -1 to rule out reset issue  ──  no result
  - DC pin moved from IO27 to IO26
    (IO27 label was cut off on board, misidentified)
  - User_Setup.h bypassed entirely via platformio.ini
    build_flags — confirmed pin definitions correct
  - SPI frequency reduced from 27MHz to 4MHz  ──  no result

Hardware Verification
  - Multimeter used to verify:
      VCC  →  3.3V  ✓
      BL   →  3.3V  ✓
      GND  →  common ground confirmed ✓
  - All wiring verified and reconfirmed:
      GND  →  ESP32 GND
      VCC  →  3.3V
      BL   →  3.3V external supply
      CLK  →  IO18
      SDA  →  IO23
      CS   →  IO5
      DC   →  IO26
      RST  →  IO4
  - Serial monitor confirmed:
      "Booting..."           ✓
      "Display initialized." ✓
    Code runs fine, SPI communication working

Display Verdict
----------------------------------------------------------------
  - Independent backlight test performed:
      VCC and BL connected to 3.3V, GND connected
      No glow — backlight completely dead
  - Conclusion: ST7735 display module is physically dead
  - Likely cause: BL connected to wrong voltage at some point
    or dead on arrival unit

Backup Display — 0802A Character LCD
----------------------------------------------------------------
  - 0802A character LCD discovered as backup
  - Independent backlight test performed — backlight alive
  - Specs:
      8 characters x 2 rows
      Text only — no graphics
      Parallel/I2C interface, not SPI
      Different library required
  - Verdict: too limited for Ghostwave UI
    Cannot display menus, signal visualizations, or graphics

Hardware Capabilities Confirmed
----------------------------------------------------------------
CC1101 Frequency Range
  - Not limited to 433MHz
  - Full range: 300MHz - 915MHz
  - Common targets:
      433MHz  ──  car keys, garage doors, weather stations
      315MHz  ──  older car remotes, US market devices
      868MHz  ──  European IoT, smart meters
      915MHz  ──  US IoT devices, LoRa

Planned Features
  - Potentiometer for real time frequency adjustment
      mapped across 300-915MHz range
  - IR capture planned as future addition
      requires separate IR module (e.g. TSOP38238)
      CC1101 handles RF only, not infrared
