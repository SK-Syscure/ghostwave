================================================================
SOFTWARE ARCHITECTURE
================================================================

Decision Made (Hazem)
----------------------------------------------------------------
  - main.cpp was becoming too large
  - Separated the scanner into its own module:

      src/
      ├── main.cpp
      ├── RFScanner.cpp
      └── RFScanner.h

  - RFScanner.h exposes only:
      rfScannerSetup()
      rfScannerLoop()

  - RFScanner.cpp contains the RF24, TFT, scanner state,
    animation, visualization and implementation details
  - main.cpp now acts only as the application entry point

Architecture Principle
----------------------------------------------------------------
  - Header = public interface
  - CPP = implementation details
  - Internal helpers and hardware objects remain private to
    RFScanner.cpp unless another module actually needs them
